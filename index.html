What this is for

Learning the pattern of each stitch — where the needle enters, what it takes, how the knot is placed, and which tissue each pattern is meant for. The animations are schematic so the geometry stays readable.

What it is not

Not a clinical protocol and not a substitute for supervised practice. Material choices, sizes and removal times vary by species, tissue and local policy — always check your own guidelines before treating any animal.

Works offline

Static pages with no accounts, no server and no tracking. Open the folder, or host it free on GitHub Pages. Your score lives in the browser tab and nowhere else.
